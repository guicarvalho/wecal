Como obter as credenciais (uma vez só):

  1. Crie um projeto em console.cloud.google.com
  2. Ative a Google Calendar API (APIs & Services → Library)
  3. Em OAuth consent screen, preencha app name e adicione seu e-mail como usuário test
  4. Crie credencial OAuth client ID tipo Web application
  5. Adicione esta URI de redirecionamento: {{ app_base_url }}/auth/google/callback
  6. Copie Client ID e Client secret para o arquivo .env na raiz do projeto e reinicie com docker compose up -d

Como pegar o link do iCloud:

  1. Abra icloud.com/calendar
  2. Selecione o calendário → botão de compartilhar → ative Public Calendar
  3. Copie o link (começa com webcal://) e cole aqui trocando webcal por https

Privacidade: o link é como uma senha — quem tiver ele vê o calendário. Gere outro quando quiser revogar.
