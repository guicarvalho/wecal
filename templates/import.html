Selecionar arquivo

Nome e cor personalizados valem para um arquivo individual. A cor deve ser clara e bem distinta das outras agendas. Em .zip, cada agenda usa o nome do arquivo interno e uma cor exclusiva.

Suporta .ics, .ical, .ifb e .vcs (arquivo único) ou um .zip com múltiplas agendas. Exportações do Google Calendar vêm como .zip — pode enviar direto.

Como exportar dos principais serviços

📅 Google Calendar

  1. Acesse calendar.google.com no computador
  2. Engrenagem ⚙️ → Configurações → Importar e exportar
  3. Seção "Exportar" → clique Exportar
  4. Baixa um .zip com um .ics por agenda
  5. Envie o .zip aqui direto

📧 Outlook / Microsoft 365

  1. Acesse outlook.office.com
  2. Engrenagem ⚙️ → Calendário → Calendários compartilhados
  3. Seção "Publicar calendário" → escolha a agenda
  4. Permissão: Pode ver todos os detalhes → Publicar
  5. Copie o link ICS, abra no navegador → baixa .ics
  6. Ou no Outlook desktop clássico: Arquivo → Salvar Calendário → .ics

🍎 Apple Calendar (iCloud)

  1. Acesse icloud.com/calendar
  2. Calendário → ícone 🔗 (compartilhar) → Calendário público
  3. Copie o link (começa com webcal://)
  4. Cole no navegador trocando para https:// → baixa .ics
  5. Ou no app Calendário no Mac: Arquivo → Exportar → .ics

📁 Outro arquivo .ics

Qualquer app que exporte .ics (iCal, vCalendar) funciona. Se vier em .zip, envie o zip inteiro.
